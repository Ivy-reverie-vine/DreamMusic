# 同录音换源与来源身份分离

状态：已接受（2026-10-04，三轮产品取舍共八项均获用户确认）；待实现。

NightDream 在网易、QQ、酷狗聚合搜索结果中只合并已确认的同一录音，并在音乐平台无法提供可靠完整版时尝试 Bilibili；自动替换仍限于同一录音且无明显额外片段的候选，其他候选由用户选择。音频、目录信息和歌词可以来自不同平台，因此保留各自的真实身份；同录音换源不改变原曲展示信息与收藏身份，手动选取其他录音作为独立条目，手动来源选择只对当前队列条目生效。

该决定部分取代 [ADR-0005](0005-audio-source-boundary.md) 中 URL 为空即终止的行为，以及旧单来源引用不能表达的跨源组合。沿用 NightDream 唯一在线入口；具体来源资源的 `mediaRef` 不改含义，不能用网易身份伪装 B 站音频，也不能把跨源结果送入网易数字 ID 下载链。第一阶段验证在线播放，保留既有本地与网易下载功能，QQ、酷狗、B 站自动下载入库另行设计。

继续固定一个来源会限制用户已确认的回退行为；直接把另一平台 URL 填入旧引用则会混淆歌词、收藏和下载身份。显式区分这些身份增加契约工作，但使换源行为可解释，避免错误内容关联。

完整行为与验收范围见 [多源匹配播放规格](../specs/multi-source-matching-playback.md)，项目复用证据见 [调研报告](../research/multi-source-matching-feasibility-2026-10-04.md)。
