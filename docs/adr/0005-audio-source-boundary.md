# 在线音频来源边界

状态：已接受（2026-08-19；普通播放与本地下载入库并存）

2026-10-04 补充：新多源播放设计由 [ADR-0009](0009-recording-matched-playback-and-source-identity.md) 部分取代本记录的“URL 为空即失败”和单来源引用约束。客户端统一访问 NightDream、本地沙箱和原有网易下载边界继续保留；新设计尚未实现，不能据此宣称当前运行时已支持自动换源。

鸿蒙端在线歌曲调用 NightDream 转发的 `/song/url/v1`，先使用普通 CDN 直链交给 AVPlayer 播放；不调用 `/song/url/match`，不拼接解灰参数。随后客户端下载普通播放文件、封面和歌词到应用沙箱并写入本地 SQLite，下载完成后把队列中的瞬态条目原位替换为本地音轨。无版权或 URL 为空时按普通播放/下载失败处理。
