- 日期：2026-10-03

## 实现

- 迷你播放器歌曲区域与两个播控按钮分开，外层没有打开播放页的点击事件。两个按钮热区为 48vp，图标保持原尺寸。
- 播放页上一首/下一首为 48vp 独立按钮，保留现有 72vp 播放/暂停容器。
- 迷你播放器和播放页共用播控执行状态：执行期间禁用按钮并忽略重复调用，完成或失败后恢复，避免准备/切歌/暂停操作重叠。
- 队列删除按钮和排序手柄均为 48vp。只有手柄捕获排序手势，歌曲内容区保留连续上下滚动。
- 拖动期间保留原行节点和顺序，用手柄变色、源行淡化、目标行描边与“松手放到第 N 项”提示预览。松手提交一次有效排列，落位描边保持 700ms。
- 目标按真实行位置及滚动偏移计算，不再按固定 70vp 行高推算。边缘允许自动滚动；拖出列表后松手、手势取消、离开页面或外部队列变化均不提交草稿。
- 排序保留当前音轨、播放模式及随机洗牌进度，沿用现有队列持久化。删除按音轨 ID 查找最新索引，避免排序后的旧索引删除错项。
