# Issue 09:歌单、收藏与播放历史

- 标签: `ready-for-agent`
- 父级: docs/PRD-v1-local-music-player.md

## What to build

自建歌单的创建/重命名/删除与加歌/移歌(歌单内顺序保留);收藏为音轨级布尔标记,自动聚合进固定歌单"我喜欢的音乐"(系统保留歌单);播放历史自动记录(500 条上限滚动淘汰),设置页可清空。歌单页展示自建歌单与"我喜欢的音乐"。

## Acceptance criteria

- [ ] 创建/重命名/删除自建歌单;删除歌单不影响音轨本身
- [ ] 音轨可加入/移出自建歌单,歌单内顺序保留并可浏览播放
- [ ] 收藏/取消收藏即时反映到"我喜欢的音乐"
- [ ] 每次播放自动写历史(音轨+时间),上限 500 条滚动淘汰
- [ ] 设置页可清空播放历史
- [ ] 系统保留歌单"我喜欢的音乐"不可删除、不可重命名
