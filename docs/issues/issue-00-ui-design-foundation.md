# Issue 00:UI 设计地基(背景图与随图取色主题系统)

- 标签: `ready-for-agent`
- 父级: docs/PRD-v1-local-music-player.md
- 设计权威: PRODUCT.md / DESIGN.md(视觉决策不得与其冲突)

## What to build

把 DESIGN.md 的"取色于景"世界落地为可用的主题系统与组件地基:设置页选择自定义背景图(PhotoViewPicker)→ 复制进沙箱并持久化;取色引擎(ImageKit 缩放读像素 → 纯逻辑取色/量化聚类/对比度钳制 → 映射 DESIGN.md 角色);全局动态主题服务(状态驱动,无图时回退铜绿默认主题);正在播放页从当前封面取色、切歌渐变过渡;按鸿蒙设计语言(大圆角卡片/柔和阴影/弥散光影/毛玻璃/克制动效)搭通用组件与五页布局骨架。

## Acceptance criteria

- [ ] 设置页可经系统选择器选背景图,复制进沙箱保存,重启后保持
- [ ] 取色引擎纯逻辑有 Hypium 单测:像素数组→角色色,断言对比度/色相分离/面积约束
- [ ] 无背景图时回退铜绿默认主题(oklch 0.55 0.095 180),不报错
- [ ] 背景图全局铺满;列表页蒙层保证白字对比度 ≥4.5:1,图片过亮自动加深蒙层
- [ ] 正在播放页主强调色从当前封面提取,切歌时约 500ms 渐变过渡
- [ ] 主题色变化即时生效;深浅色跟随系统仍可用
- [ ] DESIGN.md 中的角色(token)在 ArkUI 资源/主题服务中有唯一落地,页面不得硬编码颜色
- [ ] 底部导航为半透明玻璃底栏(内容透过可见);点击反馈为官方"沉浸光感"(触点为中心、约指尖半径光晕,光随手指快速淡出),实现依据官方沉浸光感最佳实践文档
- [ ] 正在播放页签名交互:封面如翻开黑胶唱片般轻微展开+微旋转(温和版,原型阶段请用户评审)
- [ ] 椭圆泡泡暂停按钮组件与通用卡片/胶囊控件组件落地,供后续 issue 复用
- [ ] `hvigorw assembleHap` 编译通过
