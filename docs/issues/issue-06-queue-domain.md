# Issue 06:播放队列域与队列页

- 标签: `ready-for-agent`
- 父级: docs/PRD-v1-local-music-player.md

## What to build

播放域纯逻辑核心:队列状态机、四种播放模式(顺序/单曲循环/列表循环/随机)、随机算法(不复现上一首)、断点续播位置计算、播完自动切下一首;队列与当前状态持久化到数据库;播放队列页支持**拖拽调整顺序**。此切片是单测主战场(播放域零 kit 依赖)。

## Acceptance criteria

- [ ] 播放域纯逻辑有 Hypium 单测覆盖:模式切换、列表边界(首尾)、随机不重复上一首、断点计算
- [ ] 点任一音轨即把其来源列表设为当前队列并开始播放
- [ ] 四种播放模式行为正确:顺序播完停住;单曲循环;列表循环;随机遍历
- [ ] 播放队列页展示当前队列,可拖拽调序
- [ ] 队列/当前音轨/播放模式/进度持久化,重启后恢复并断点续播
