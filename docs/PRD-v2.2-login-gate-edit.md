# PRD v2.2: 登录门禁 + 自动绑定引导 + 歌曲编辑 + 背景图/弹层修复

- 阶段: 8/16 用户反馈轮次
- 依据: 用户真机反馈(背景图"大框常驻"、切换需杀进程)+ 需求(不登录无法进入/注册邀请码/未绑定自动弹二维码/歌曲编辑)

## 问题修复

1. **背景图"大框常驻"**: 根因是底部弹层(`bindSheet`)拖拽关闭后状态未复位,任何刷新都会重新弹出;修复:显隐用独立 `showSheet` 状态 + `onDisappear` 复位(设置页、音乐库弹层同步修)
2. **切换背景图需杀进程**: 根因是页面持有 `theme` 的 `@Prop` 拷贝,设置页改的是拷贝,主壳 Index 的全局背景收不到变更;修复:全部页面/组件改为 `@State theme = ThemeService.getInstance()` 单例引用,变更即时传播到主壳背景层

## 新功能

1. **登录门禁(可跳过)**: 启动先检查会话(有会话则 `/auth/me` 校验,401 清本地回登录页;中间层临时不可达保留会话进入);未登录先弹登录页,但提供"跳过,先听本地歌";本地歌不登录可听,在线搜索/下载/歌词使用时才弹登录盖层
2. **注册**: 登录页可切换注册模式,需用户名/密码/**邀请码**(默认 `dreammusic`,可改)
3. **自动 QR 绑定**: 登录成功且未绑定(或绑定失效)→ 登录页内直接进入二维码绑定步骤(可"暂不绑定");已登录用户冷启动未绑定 → 主界面自动弹出绑定弹层;绑定逻辑收敛为可复用组件 `QrBindView`(设置页共用)
4. **歌曲编辑**: 音乐库行"⋯"弹层新增"编辑信息"(歌名/作者),保存后更新 DB 并同步艺术家聚合计数与专辑行作者标签
5. **动态手写 Logo**: 引入 D:\Blog\ivy-move-font 笔迹数据,登录页品牌字"IvyReverie"逐笔书写动画(ArkUI Path strokeDashOffset,3s,减弱动效即显);副标题改为"梦有回响,点滴成光"
